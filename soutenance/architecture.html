Architecture de la plateforme

Une API REST Node/TypeScript adossée à MongoDB, et une application terrain React Native conçue pour fonctionner en zone blanche. Trois schémas : le déploiement, le cheminement d'une requête, et le cycle d'un scan hors ligne.

1 — Le déploiement en production

Deux conteneurs sur une seule machine. Ils communiquent par un réseau Docker privé : la base n'est jamais exposée, ni à Internet, ni au réseau de l'hôte.

2 — Le cheminement d'une requête dans l'API

Découpage N-Tier strict. Chaque couche a une responsabilité unique et ne déborde jamais : un service ne voit jamais un document Mongoose, un contrôleur ne voit jamais le modèle.

CarbonFootprintService

Méthodologie ADEME Base Carbone® : fabrication amortie sur la durée de vie, plus tonnes × km × facteur pour le transport.

AdemeFactorService

Facteurs d'émission en stale-while-revalidate : cache 24 h et repli codé en dur. L'API reste fonctionnelle si l'ADEME est indisponible.

ResourceAllocationService

Algorithme du banquier appliqué à l'allocation d'équipements : détection d'état non sûr, refus en 422.

3 — Le cycle d'un scan hors ligne

C'est le cœur du sujet : l'agent scanne en zone blanche, l'interface répond immédiatement, et la synchronisation arrive plus tard sans perte de données.

Le détail qui compte. La fenêtre anti-doublon court depuis la dernière vue du code, pas depuis le dernier scan accepté. Sans ce rafraîchissement, viser un QR en continu le réenregistrerait toutes les 1,5 seconde, la caméra produisant des dizaines d'images par seconde. Il faut que le code quitte le champ pour être réaccepté.

Provisionnement administré

Aucune inscription publique : POST /auth/register est réservé à l'admin. Le rôle vient d'une autorité, jamais du demandeur — sans quoi n'importe qui se déclarerait administrateur.

Mot de passe temporaire

Tout compte créé par un tiers est marqué. Toutes les routes métier répondent 403 tant que son titulaire ne l'a pas remplacé.

Matrice testée

requireRole expose les rôles qu'il autorise ; un test relit la matrice réelle. La documentation des permissions est le code.

5 — Points techniques défendables

Ce qu'on peut montrer en direct plutôt que raconter.

Verrouillage optimiste

Chaque entité porte une version mappée sur __v. Une écriture concurrente obtient 409 au lieu d'écraser — la brique qui rend le mode hors ligne sûr.

Transactions ACID

L'allocation d'un lot d'équipements est atomique : à la première erreur, tout le lot est annulé.

Change Streams → SSE

MongoDB pousse ses changements ; l'API les relaie en Server-Sent Events vers les terminaux du secteur.

Indexation chirurgicale

Composés, géospatiaux 2dsphere, et un index partiel qui n'indexe que les équipements perdus.

Séries temporelles

Les métriques de monitoring vivent dans une collection time series dédiée.

UI optimiste et rollback

Le statut cible est appliqué immédiatement en local ; previousStatus permet d'annuler l'affichage si la synchro échoue définitivement.
